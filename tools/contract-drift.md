# فحص انحراف العقد

يقارن `contract-drift.mjs` عمليات `paths` في `contracts/openapi.yaml` بمزخرفات `@Controller` و`@Get` و`@Post` و`@Put` و`@Patch` و`@Delete` في `apps/api/src/**/*.controller.ts`. يوحّد أسماء المعاملات، فمثلًا `:fileId` و`{file_id}` متطابقان، ولا يضيف بادئة التشغيل `/v1` لأنها ليست جزءًا من مفاتيح العقد.

## التشغيل

```bash
node tools/contract-drift.mjs
node --test tools/contract-drift.test.mjs
```

يطبع عدد العمليات في الجانبين، ثم سطرًا لكل مسار موجود في العقد فقط (`CONTRACT_ONLY`) أو في وحدات التحكم فقط (`CONTROLLER_ONLY`). وجود الفروق **تحذير لا فشل**: رمز الخروج الافتراضي `0` حتى يصلح للتشغيل في CI دون إيقافه. عند `GITHUB_ACTIONS=true` يطبع أيضًا رسالة تحذير بصيغة GitHub. للفحص المحلي الصارم فقط استخدم `--strict` فيصير الخروج `1` عند وجود فروق.

يمكن تغيير المدخلات بمتغيري `CONTRACT_DRIFT_OPENAPI` و`CONTRACT_DRIFT_CONTROLLERS`، أو بتمرير مسار العقد ثم مجلد وحدات التحكم كوسيطين. لا يحتاج الأداة إلى حزم خارجية، ولا يعدّل العقد أو الشفرة، ولا يغيّر إعدادات CI.

هذا فحص مسارات وطرق HTTP فقط؛ لا يثبت تطابق أجسام الطلبات أو الاستجابات أو الصلاحيات. القيم غير النصية أو خيارات المزخرفات المركّبة تحتاج توسيع القارئ قبل اعتمادها.
