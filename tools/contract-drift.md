# فحص انحراف العقد

يقارن `contract-drift.mjs` عمليات `paths` في `contracts/openapi.yaml` بمزخرفات `@Controller` و`@Get` و`@Post` و`@Put` و`@Patch` و`@Delete` في `apps/api/src`. يفحص كل ملف `*.ts` — لا اللاحقة `.controller.ts` وحدها، فالمتحكم قد يجاور خدمته في ملف واحد كوحدات `commerce/` — ويستثني مجلد `generated/` وملفات `*.spec.ts`، ويحتفظ بما فيه `@Controller(` فعلًا. يوحّد أسماء المعاملات، فمثلًا `:fileId` و`{file_id}` متطابقان، ولا يضيف بادئة التشغيل `/v1` لأنها ليست جزءًا من مفاتيح العقد؛ واستثناءات `setGlobalPrefix` لا تؤثر في المقارنة لأن البادئة لا تُضاف إلى أيّ جانب أصلًا.

## التشغيل

```bash
node tools/contract-drift.mjs
node --test tools/contract-drift.test.mjs
```

يطبع عدد العمليات في الجانبين وعدد ملفات المتحكمات المقروءة، ثم سطرًا لكل مسار موجود في العقد فقط (`CONTRACT_ONLY`) أو في وحدات التحكم فقط (`CONTROLLER_ONLY`). وجود الفروق **تحذير لا فشل**: رمز الخروج الافتراضي `0` حتى يصلح للتشغيل في CI دون إيقافه. عند `GITHUB_ACTIONS=true` يطبع أيضًا رسالة تحذير بصيغة GitHub.

حارس الاكتشاف: كل مزخرف `@Controller` وسيطه ليس نصًا حرفيًا — الصيغة الكائنية `@Controller({ path })` أو متغير — لا تُحلَّل بادئته، فيُطبع عنه سطر `UNPARSED_CONTROLLER <ملف>:<سطر>` بدل أن يغيب عن المقارنة بصمت فتبدو النتيجة «لا فرق». للفحص المحلي الصارم استخدم `--strict` فيصير الخروج `1` عند وجود فروق أو مزخرفات غير محلَّلة.

يمكن تغيير المدخلات بمتغيري `CONTRACT_DRIFT_OPENAPI` و`CONTRACT_DRIFT_CONTROLLERS`، أو بتمرير مسار العقد ثم مجلد وحدات التحكم كوسيطين. لا تحتاج الأداة إلى حزم خارجية، ولا تعدّل العقد أو الشفرة، ولا تغيّر إعدادات CI.

هذا فحص مسارات وطرق HTTP فقط؛ لا يثبت تطابق أجسام الطلبات أو الاستجابات أو الصلاحيات. الصيغة الكائنية وخيارات المزخرفات المركّبة تُنبَّه بها وحدها؛ تحتاج توسيع القارئ قبل اعتمادها.
