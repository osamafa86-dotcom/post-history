# asr-bench

اختبار التفريغ العربي المقارن. يملكه وكيل الذكاء الاصطناعي.

- المدخل: عينة من تسجيلات ميدانية (تُشار إليها بمعرّف؛ لا تُرفع إلى المستودع) مع الحقيقة الأرضية المفرّغة يدويًا، وتتضمن عينة صادمة.
- المزوّدون: ElevenLabs Scribe v2، Munsit، Gemini، Whisper محلي عبر FFmpeg 8 على GPU، نموذج Mistral العربي.
- المقاييس: WER، خطأ الأسماء والأماكن، نسبة الأسماء المختلقة، نسبة الرفض لكل مزوّد على العينة الصادمة، كلفة الدقيقة، زمن المعالجة.
- المخرج: ملف لكل تشغيل بمخطط `contracts/schemas/measurement.json` في `docs/measurements/asr-bench/`، وتقرير قصير بتوصية.
- لا يُرسل أي ملف حقيقي إلى مزوّد خارجي قبل موافقة المنسّق المكتوبة في PR.
