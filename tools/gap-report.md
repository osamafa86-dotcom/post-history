# مولّد تقرير الفجوات

يقابل `gap-report.mjs` اختبارات القبول في الخطة بما نُفّذ منها سكربتًا وما له قياس موثق، ويكتب النتيجة في `docs/plan/gap-report.md` — ملف مولَّد لا يُحرَّر يدويًا.

## المصادر

- قسم «اختبارات القبول» في `docs/plan/الخطة-النسخة-الثالثة.md` (الصفوف الـ 22 بترتيبها).
- كتالوج `tools/acceptance/lib/catalog.mjs`: `CATALOG` لصفوف الخطة و`EXTRA` للاختبارات الإضافية من قرارات الأمن والفجوات. الربط بين صف الخطة ومدخلة الكتالوج بنص المعيار (أطول بادئة مشتركة، عتبة 0.6)، فلا يكسره تحرير طفيف على أحد المصدرين، والتعذر خطأ صريح لا تخمين.
- كل ملفات JSON تحت `docs/measurements/` (بمخطط `contracts/schemas/measurement.json`): الربط بـ `test_name` أولًا، ثم باسم السكربت من اسم الملف `<التاريخ>-<الاسم>-<وصف>.json` عند غيابه. «آخر قياس» هو الأحدث بتاريخ الانتهاء. القياسات التي لا تطابق اسمًا في الكتالوج تُحسب يتيمة (نتائج أدوات أخرى) ولا تُعد فجوة.
- عمود «الحزمة المالكة» يُقرأ من `docs/plan/gap-analysis-2026-10.md` — وثيقة تاريخية **لا تُعدَّل** أبدًا؛ من أراد تحديث حزمة يحرر تلك الوثيقة في PR مستقل.

مسار السكربت المعروض أول وجود من: `tools/acceptance/scripts/<الاسم>.mjs` ثم `tools/acceptance/live/<الاسم>.mjs` ثم `tools/acceptance/field/<الاسم>.md`.

## التشغيل

```bash
node tools/gap-report.mjs            # يطبع التقرير ويكتب docs/plan/gap-report.md
node tools/gap-report.mjs --json     # الصفوف JSON بدل الجدول (ويكتب الملف أيضًا)
node tools/gap-report.mjs --check    # لا يكتب؛ خروج 1 إن اختلف المخزن عن المولَّد
```

الخروج: `0` سليم، `1` فشل `--check`، `2` تعذر قراءة المدخلات.

تُتجاوز المسارات ببيئة: `GAP_REPORT_PLAN` و`GAP_REPORT_CATALOG` و`GAP_REPORT_MEASUREMENTS` و`GAP_REPORT_ANALYSIS` و`GAP_REPORT_OUT` (تستعملها الاختبارات على حقول مؤقتة).

## الاختبارات

```bash
node --test tools/gap-report.test.mjs
```

حقول صغيرة في مجلد مؤقت: ثلاثة صفوف خطة ومدخلة إضافية، وقياسات تغطي الأحدث-يُختار، والربط باسم الملف بلا `test_name`، واليتيم والتالف، وذهاب `--check` وإيابه.

## CI

اقتراح للمالك: خطوة تحذير `node tools/gap-report.mjs --check` تفشل بلين (أو تُعلّق) عندما يتخلف الملف المخزن عن القياسات الجديدة. ملفات `.github/` ليست ضمن نطاق هذه المهمة.
