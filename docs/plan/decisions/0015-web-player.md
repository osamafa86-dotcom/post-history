# 0015 — اختيار مشغّل الويب بقياس

- الحالة: مقترح
- التاريخ: 2026-10-24
- المسؤول: الويب
- بند ملحق القرارات: 6

## السياق

التذكرة #89 تطلب HLS والترجمة العربية وصور شريط الزمن ولوحة المفاتيح على Chrome وSafari. أداة العامل #212 تنتج قائمتَي HLS fMP4 من عينات VFR وHLG مصطنعة، وWebVTT عربيًا وصفيحة مصغّرات. التطبيق الحالي يمرر MP4 عبر BFF دون كشف روابط التخزين.

## الخيارات

1. Video.js 10.2.0 بحزمته React ومحوّل HLS.js 10.2.0، مع CompatVideoSkin. ليست واجهة إضافات v8؛ عناصر الترجمة والمصغّرات والاختصارات مدمجة في v10، ولا نحتاج إضافات إعلانات أو تحليلات.
2. Shaka Player 5.3.2 مع UI المضمّنة. توفر النصوص والمصغرات والاختصارات دون إضافات مستقلة؛ CSS الافتراضي يتضمن خطًا خارجيًا يجب حذفه.

## القرار

الترشيح الأولي Shaka لأن صور العامل النسبية ظهرت معه بعد تمرير عنوان VTT مطلق من الأصل نفسه، بينما فشلت في Video.js 10.2.0: طلب sprite.jpg نسبة إلى صفحة الاختبار بدل ملف VTT. **لا اعتماد نهائي بعد**: لم يكتمل قياس لوحة المفاتيح أو Safari، ويحتاج اتجاه النص العربي المختلط في UITextDisplayer إلى معالجة واختبار قبل الاختيار والاستبدال في التطبيق.

## الدليل

`docs/measurements/web/2026-10-24-player-preliminary.json` نتيجة partial. الشيفرة وطريقة الإعادة في `apps/web/scripts/player-bench/`.

لوحظ تشغيل HLS وفك إطارات على Chrome Headless Shell 156.0.8078.47 في Linux، على حالتي العامل. الترجمة الأصلية عرضت الإشارات العربية، وواجهة Shaka HTML أبعدت الترجمة عن أدوات التحكم لكنها لم تجتز مراجعة الاتجاه المختلط. حجم حزمة تجريبية كاملة ليس حجم الزيادة في Next: حزمة Video.js تضم React في هذه التجربة.

## التبعات

تبقى الحزمتان محصورتين في بيئة المقارنة المؤقتة، دون تغيير اعتماديات التطبيق أو تشغيله. بعد اكتمال البوابات يُحدّث هذا ADR بالاختيار المقيس، ويُضاف المشغّل المختار وحده إلى التطبيق، وتبقى إعادة مقارنة الآخر اختيارية خارج حزمة الإنتاج.

دمج HLS على المواد الحقيقية محجوب أيضًا بعقد الخادم: endpoint الحالي يوقع كائنًا واحدًا ولا يتيح مقاطع الحزمة أو مصغّراتها. طُلب تكليف مالك العقود والخادم في #89؛ لا تغييرات على حزمهم ضمن هذا الطلب.
