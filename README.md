# post-history — منصة المكتبة المرئية لشبكة فلسطين بوست

مستودع واحد (monorepo) لمنصة تستقبل مواد المراسلين من الميدان، وتعيد إنتاجها في غرفة الأخبار بمساعدة الذكاء الاصطناعي، وتبيع تراخيصها مع نصيب تلقائي لكل مراسل.

القاعدة الحاكمة: الأصل لا يُمس، ولا تُباع مادة إلا بأصل متحقق واعتماد تحريري وحقوق موثقة، والذكاء الاصطناعي يجهّز ولا ينشر.

## ابدأ من هنا

1. `docs/plan/الخطة-النسخة-الثالثة.md` — الخطة المعتمدة (المرجع الوحيد للنطاق والقرارات).
2. `docs/plan/مقترح-بدء-البناء-وفريق-الوكلاء.md` — ترتيب البناء في مرحلة التأسيس وتعريف «منجز».
3. `docs/plan/أدوار-الوكلاء-وتعليمات-البدء.md` — من يملك أي حزمة وما تعليماته الأولى.
4. `CLAUDE.md` — اتفاقيات العمل في المستودع (إلزامية لكل وكيل وكل بشري).
5. `contracts/` — العقود: OpenAPI ومخططات JSON. كل حزمة تُبنى ضدها.

## الهيكل

| المسار | المحتوى | المالك |
| --- | --- | --- |
| `contracts/` | `openapi.yaml`، `schemas/` | وكيل العقود والبيانات |
| `apps/api/` | الخادم الرئيسي (NestJS، خادم بوحدات) | وكيل الخادم (و`src/db` لوكيل العقود) |
| `apps/web/` | الويب (Next.js): غرفة الأخبار، الإدارة، المتجر لاحقًا | وكيل الويب |
| `apps/ios/` | تطبيق المراسلين (SwiftUI) | وكيل iOS |
| `apps/android/` | تطبيق المراسلين (Jetpack Compose) | وكيل أندرويد |
| `workers/media/` | معالجة الوسائط (Python + FFmpeg) | وكيل الوسائط |
| `workers/ai/` | بوابة الذكاء الاصطناعي والمسار المحلي (Python) | وكيل الذكاء الاصطناعي |
| `infra/` | compose، tusd، terraform | وكيل الرفع والبنية |
| `tools/` | netlab، asr-bench، render-bench، acceptance | وكلاء الجودة والبنية والوسائط والذكاء الاصطناعي |
| `docs/plan/` | الخطة، سجل القرارات (ADR) | المنسّق |
| `docs/measurements/` | نتائج القياس بصيغة `contracts/schemas/measurement.json` | كل من يقيس |

## التشغيل المحلي

```bash
cp infra/compose/.env.example infra/compose/.env
docker compose -f infra/compose/docker-compose.yml up -d
```

يشغّل Postgres وRedis وMinIO (بديل S3 محليًا) وtusd مُعدًّا بأجزاء متساوية كما يشترط R2.

## المرحلة الحالية

مرحلة التأسيس (الأسابيع 1–6): العقود v0، نموذج الرفع على أجهزة فعلية، اختبار التفريغ، قياس التصدير، الوارد الحي. لا متجر ولا دفتر أستاذ ولا محرر قبل بوابة الأسبوع السادس وتجربة الصرف.
