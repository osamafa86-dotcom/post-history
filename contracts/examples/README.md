# examples — أمثلة التحقق للعقود

لكل مخطط في `contracts/schemas/<name>.json` مجلدان:

- `<name>/valid/*.json` — يجب أن تجتاز المخطط كلها.
- `<name>/invalid/*.json` — يجب أن يفشل كل ملف منها على حدة (ملف لكل سبب فشل، والسبب في اسم الملف).

يفحصها `contracts/scripts/check.sh` بـ `ajv validate`، ويفشل إن غاب عن مخطط مجلد منهما. هذه الأمثلة
هي اختبار العقد: أي تغيير في مخطط يجب أن يُثبت هنا ما صار يُقبل وما صار يُرفض.

لا بيانات حقيقية هنا: المعرّفات والأسماء مصطنعة، ولا إحداثيات ولا أسماء مصادر.
