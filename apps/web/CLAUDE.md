# apps/web — الويب

المالك: وكيل الويب.

## التقنية

- TypeScript + Next.js + Tailwind. عميل API مولَّد من `contracts/openapi.yaml`.
- RTL أولًا مع إنجليزية كاملة؛ كل نص في ملفات موارد (`ar`, `en`).

## نطاق التأسيس

1. الوارد الحي: المواد الواردة والرفع الجاري ونسبته عبر WebSocket، زر «اطّلعت»، عدّاد التصعيد.
2. راسم النماذج الديناميكي من `contracts/schemas/upload-form.json` (الأنواع العشرة، الشرطية، التحقق) مع اختبار مطابقة مشترك مع التطبيقين (`tools/acceptance/form-conformance/`).
3. لوحة الإنتاج الأولية: أعمدة الحالات التحريرية، حجز المادة، التعليق على التوقيت.
4. منصة اختبار المشغل: Video.js 10 مقابل Shaka على HLS نفسه؛ النتيجة في `docs/measurements/web/`.

## قواعد الحزمة

- لا يُعرض اسم مصدر محمي ولا موقع دقيق لغير الأدوار المخوّلة، ولا في عناوين الصفحات أو التنبيهات.
- المعاينات بعلامة مائية وروابط موقّعة قصيرة العمر؛ لا أزرار استخراج للأصل للمشاهد العام.
- المحرر لاحقًا وحدة مستقلة عن المشغل؛ لا تُبنى الآن.
- اختبارات واجهة آلية لكل شاشة في النطاق.
