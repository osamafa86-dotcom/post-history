# أرباح المراسل وطلبات الصرف التجريبية

المهمة #420 من #352، وفق العقد وADR 0033. المنسّق يقوم مقام مالك الحزمة، ويلزم اعتماد الجودة والأمن قبل الدمج.

- يظهر المدخل للمراسل وحده. تتحقق الشاشة أيضًا من Me قبل أي استعلام أرباح، ويبقى الخادم حكم الدور والنطاق. عند 401 أو 403 تختفي البيانات المالية ولا تظهر رسالة الخادم الخام.
- لكل عملة: المعلّق، والمتاح للطلب بعد الاحتياطي، والحد الأدنى، ووقت الرصيد كما أعاده الخادم. التنسيق محلي بالعربية والإنجليزية، من الوحدات الصغرى بـBigDecimal دون تقريب ثنائي.
- طلب الصرف هو **كامل requestable المعروض**؛ الزر يصف ذلك، ولا يسمح بصفر أو مبلغ دون minimum. لا حساب محلي للرصيد ولا خصم تفاؤلي. يعاد الرصيد وحالة الطلب من الخادم بعد النجاح.
- كشف القيود بمرشح العملة والحالة وصفحات بالمؤشر. يعرض النوع والمبلغ بإشارته والحالة والتاريخ، بلا مشترٍ أو مؤسسة أو سعر بيع أو معلومات معتمدين. الطلبات بصفحات مستقلة وحالاتها من العقد.
- كل أجسام الشبكة وطرقها من العميل المولّد، ولا نماذج API مكتوبة يدويًا أو تبعيات جديدة.

## محاولة الطلب

المفتاح والجسم ثابتان لمحاولة واحدة، ويُحفظان في SavedStateHandle قبل الإرسال، لا في السجل أو الإشعارات. المفتاح خاص بمساحة نموذج العرض للمستخدم، لا لمستخدم آخر. انقطاع الشبكة أو 409 يتركان محاولة معلّقة؛ زر إعادة الإرسال يستعمل الجسم والمفتاح نفسيهما. لا يسمح بطلب جديد أثناء محاولة معلّقة أو جارٍ إرسالها. 422 رفض قطعي، فينتهي مفتاح المحاولة ويُطلب تحديث الرصيد قبل محاولة جديدة. لا تغيّر الاستجابة المرفوضة الأرصدة أو تضيف طلبًا محليًا.

ترك الشاشة يلغي أعمال الشبكة ويمحو البيانات المعروضة، مع حفظ محاولة لم تتأكد نتيجتها للمستخدم نفسه. بعد العودة تتحقق الهوية والدور وتقرأ الأرصدة من جديد قبل إتاحة أي إرسال.

## تجريبي فقط

وسم تجريبي ظاهر على الشاشة، وعلى زر الطلب، وفي قائمة الطلبات. القناة الوحيدة sandbox؛ لا اختيار قناة أو حساب بنكي أو حقل دفع. النجاح ليس إثبات تحويل مال حقيقي.

## التحقق

اختبارات EarningsViewModelTest تغطي تنسيق المبالغ الموقعة، وحد الطلب، والتحقق من دور المراسل، وإعادة نفس الجسم والمفتاح بعد إعادة إنشاء النموذج، ومنع طلبين جاريين، و409/422 بلا أثر محلي، وتحديث الأرصدة بعد النجاح، ومرشحات الكشف وصفحاته وصفحات الطلبات، وفشل صفحة، ومحو البيانات عند المنع أو ترك الشاشة.

فُحصت XML ومطابقة مفاتيح الموارد محليًا. محاولة Gradle المحلية توقفت عند تنزيل التوزيعة برسالة Network is unreachable؛ لا SDK أو محاكي في هذه البيئة. اختبارات Kotlin والبناء وlint تُحسم بنتيجة CI، ولا يُدّعى نجاحها أو تشغيل شاشة/دفع فعلي قبل ذلك. لا ملف قياس تشغيل مصطنع.
